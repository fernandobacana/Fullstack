Star Defender

Um jogo de nave espacial feito com HTML, CSS e JavaScript puro.

▶ Jogar Agora

Sobre o Jogo

No jogo star defender voce controla uma nave, onde está tendo uma invasão galatica de inimigos , seu objetivo é derrota-los e conquistar a paz intergalaxica.

Tutorial]

🎮 ← → — Move a nave para os lados

🔫 Espaço — Atira

🔄 Enter — Reinicia após Game Over

Objetivo

Destrua todos os inimigos de cada onda para avançar. Você tem 3 vidas. Perde uma vida quando um inimigo te atinge ou quando atravessa sua linha de defesa.

Inimigos

👾 Alienígena Comum (roxo) — 1 vida, vale 10 pontos

🔴 Alienígena Elite (vermelho) — 2 vidas, vale 25 pontos

Power-ups

⚡ Tiro Duplo (azul) — Atire dois projéteis por 8 segundos

🛡️ Escudo (verde) — Absorve 1 tiro inimigo

Tecnologias

HTML / Canvas / CSS / JavaScript
